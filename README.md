# V2rayNG Pro

A maintained fork of v2rayNG focused on configuration testing, traffic visibility and sane default routing behavior.

## Features

- Automated configuration testing
- Per-configuration upload and download statistics
- Total subscription traffic usage
- Smart routing with Proxy + Direct mode
- Improved defaults for restricted network environments
